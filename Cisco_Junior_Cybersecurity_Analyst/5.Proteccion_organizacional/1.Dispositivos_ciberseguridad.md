# Seguridad de Red y Análisis de Puertos

## Dispositivos de Seguridad
Los dispositivos de seguridad pueden ser equipos independientes, como un enrutador (router), o herramientas de software que se ejecutan en un dispositivo de red. Se dividen en seis categorías generales:

* **Routers (Enrutadores):** Si bien se utilizan principalmente para interconectar varios segmentos de red, generalmente también proporcionan capacidades básicas de filtrado de tráfico. Esta información puede ayudar a definir qué equipos de un segmento de red determinado pueden comunicarse con qué otros segmentos.
* **Cortafuegos (Firewalls):** Analizan más a fondo el tráfico de red e identifican comportamientos maliciosos que deben bloquearse. Pueden tener políticas de seguridad sofisticadas aplicadas al tráfico que los atraviesa.
* **Sistemas de Prevención de Intrusiones (IPS):** Utilizan un conjunto de firmas de red para detectar coincidencias y bloquear ataques o tráfico malicioso.
* **Redes Privadas Virtuales (VPN):** Permiten que los empleados remotos usen un túnel cifrado seguro desde su computadora móvil para conectarse de forma segura a la red de la organización. También pueden interconectar de forma segura diferentes sucursales con la red de la oficina central.
* **Antimalware / Antivirus:** Sistemas que utilizan firmas o análisis de comportamiento de las aplicaciones para identificar y bloquear la ejecución de código malicioso.
* **Otros dispositivos de seguridad:** Incluyen dispositivos de seguridad web y de correo electrónico, hardware de descifrado, servidores de control de acceso de clientes y sistemas de gestión de seguridad.

## Cortafuegos (Firewalls)
En las redes de computadoras, un firewall está diseñado para controlar o filtrar qué comunicaciones se permiten ingresar y cuáles se permiten salir de un dispositivo o red. 

Se puede instalar un firewall en una sola computadora con el propósito de proteger exclusivamente a ese equipo (**firewall basado en host**), o puede ser un dispositivo de red independiente que protege una red completa y a todos los dispositivos dentro de ella (**firewall basado en red**). A medida que los ataques informáticos se han vuelto más sofisticados, se han desarrollado nuevos tipos de cortafuegos para diferentes propósitos.

### Tipos de Firewalls
* **De capa de red:** Filtra las comunicaciones según las direcciones IP de origen y destino.
* **De capa de transporte:** Filtra las comunicaciones según los puertos de datos de origen y destino, así como los estados de la conexión.
* **De capa de aplicación:** Filtra las comunicaciones en función de una aplicación, programa o servicio específico.
* **Sensible al contexto:** Filtra las comunicaciones según el usuario, el dispositivo, la función, el tipo de aplicación y el perfil de amenaza.
* **Servidor proxy:** Filtra las solicitudes de contenido web, como URL, nombres de dominio y tipos de medios.
* **Servidor proxy inverso:** Colocados frente a servidores web, los servidores proxy inversos protegen, ocultan, descargan y distribuyen el acceso a dichos servidores.
* **Traducción de direcciones de red (NAT):** Este cortafuegos oculta o enmascara las direcciones IP privadas de los hosts internos de la red hacia el exterior.
* **Basado en el host:** Filtra puertos y llamadas de servicios del sistema en un solo sistema operativo o computadora.

## Análisis de Puertos (Port Scanning)
En redes, a cada aplicación que se ejecuta en un dispositivo se le asigna un identificador llamado **número de puerto**. Este número se utiliza en ambos extremos de la transmisión para asegurar que los datos lleguen a la aplicación correcta. 

El escaneo de puertos es el proceso de comprobar una computadora, un servidor u otro host de red para conocer qué puertos están abiertos. Un administrador de red puede usarlo de manera preventiva para verificar las políticas de seguridad, pero también puede ser usado maliciosamente como una herramienta de reconocimiento para identificar el sistema operativo y los servicios vulnerables en un objetivo.

### Estados de los Puertos
Al ejecutar una herramienta de escaneo (como Nmap o Zenmap), el análisis reportará los servicios en ejecución y devolverá una de las siguientes respuestas para cada puerto:

* **Abierto / Aceptado:** Significa que otros dispositivos de red pueden acceder al puerto o servicio que se ejecuta en la computadora.
* **Cerrado / Denegado / Sin escuchar:** Significa que el puerto o servicio no se está ejecutando en el equipo y, por lo tanto, no se puede explotar.
* **Filtrado / Eliminado / Bloqueado:** Significa que el acceso al puerto o servicio está bloqueado por un firewall y, por lo tanto, no se puede determinar su estado real ni explotar de forma directa.

### Metodología de Escaneo
* **Escaneo local:** Se realiza utilizando herramientas como Zenmap o Nmap apuntando a la dirección IP privada del equipo dentro de la red local (ej. verificando servicios web o de correo).
* **Escaneo externo:** Para ejecutar un análisis desde fuera de la red (desde Internet), se debe escanear la dirección IP pública del enrutador o firewall. Si el escáner detecta puertos abiertos como el `21` (FTP), `22` (SSH), `25` (SMTP), `80` (HTTP), `443` (HTTPS) o `3389` (RDP), indica que el reenvío de puertos (*Port Forwarding*) está habilitado en el enrutador hacia la red privada.

> **Conclusión de Seguridad:** Si un escaneo de puertos reporta un estado **"Abierto"**, significa que el servicio que se ejecuta en la red puede ser accedido por otros dispositivos. Por lo tanto, si dicho servicio contiene una vulnerabilidad sin parchear, puede ser explotado activamente por un atacante.
