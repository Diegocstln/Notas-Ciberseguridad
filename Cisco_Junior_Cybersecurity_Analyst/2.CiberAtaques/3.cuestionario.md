## Ejercicio: Identificación de Malware

A continuación, se relacionan las descripciones con su tipo de malware correspondiente a modo de repaso:

* **Spyware:** Malware diseñado para rastrear la actividad en línea y capturar datos del usuario.
* **Adware:** Software que entrega anuncios automáticamente.
* **Ransomware:** Un tipo de malware que mantiene un sistema de computación cautivo hasta que se realiza un pago al atacante.
* **Virus:** Código malicioso que se adjunta a programas legítimos y que normalmente se propaga a través de unidades USB, medios ópticos, recursos compartidos de red o correo electrónico.
* **Gusanos (Worms):** Código malicioso que se replica atacando de manera independiente las vulnerabilidades en las redes.
